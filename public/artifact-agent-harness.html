The Harness, Not the Framework

One tool contract, an append-only ledger, and replay as the requirement the architecture falls out of.

Reference implementation · built for my own concept systems

The problem

An agent framework gives you a loop, a prompt template and a tool registry in an afternoon. They're good at the part that was never the hard part.

What they don't hand you is an answer to the question that actually gets asked eighteen months later, usually by someone who doesn't care how the model works: why did this happen, and would it happen the same way today. Logs don't answer that. A log tells you what got printed. It doesn't let you put the decision back together.

So I start from replay and let the architecture fall out of it. If a run has to be reconstructable, then every non-deterministic input gets recorded as a value rather than a reference, every step becomes an addressable event, and the loop becomes a fold over an append-only ledger instead of a while True. Once that's settled, the rest stops being a matter of taste. Tools turn into pure functions of a typed request. The model becomes one step type among several. Anything that leaves our boundary goes through a gate that can refuse.

That's also why I keep the loop. The loop is where the invariants live, and a framework that owns the loop owns them instead. Below are the ones I care about most, then a worked run that exercises them, then the two places this design admits it can't help you.

harness/contract.py — four things a tool has to admit about itself Python 
"""harness/contract.py — the tool contract.

Invariants this file exists to hold:

  H1  A tool that does not declare `idempotent` is never retried after a
      timeout. A timeout means unknown, not failed.
  H2  The idempotency key is derived from the run id, the tool, its version
      and the declared key fields only. A retry inside a run collides on
      purpose. A different run never does.
  H3  Timeout and attempt budgets are per tool, not global. A 400ms cache
      read and a 30s filing call do not share a policy.
  H4  An irreversible effect declares its compensating action, or it does
      not load.
  H5  A write we cannot retry declares how to find out whether it landed, or
      it does not load. "We don't know" is only acceptable if someone can go
      and look.
"""
from __future__ import annotations

import hashlib
import json
from dataclasses import dataclass, field
from typing import Any, Mapping

READ = "read"                  # no state change anywhere
WRITE = "write"                # changes state, reversible by us
IRREVERSIBLE = "irreversible"  # leaves our boundary: filed, sent, paid

EFFECTS = (READ, WRITE, IRREVERSIBLE)


class ContractError(ValueError):
    pass


@dataclass(frozen=True)
class ToolSpec:
    name: str
    version: str
    effect: str
    timeout_s: float
    max_attempts: int
    idempotent: bool = False
    key_fields: tuple[str, ...] = ()
    compensating_action: str | None = None
    reconcile_with: str | None = None
    requires_approval: bool = False

    def __post_init__(self) -> None:
        if self.effect not in EFFECTS:
            raise ContractError(f"{self.name}: unknown effect {self.effect!r}")
        if self.effect == READ and not self.idempotent:
            raise ContractError(f"{self.name}: a read is idempotent by definition")
        # H4
        if self.effect == IRREVERSIBLE and not self.compensating_action:
            raise ContractError(
                f"{self.name}: irreversible tools must name a compensating action"
            )
        if self.effect == IRREVERSIBLE and not self.requires_approval:
            raise ContractError(f"{self.name}: irreversible tools require approval")
        if self.max_attempts < 1:
            raise ContractError(f"{self.name}: max_attempts must be >= 1")
        # H1, stated as a type-level fact rather than a comment in the caller
        if self.max_attempts > 1 and not self.idempotent:
            raise ContractError(
                f"{self.name}: non-idempotent tools cannot declare retries"
            )
        if self.idempotent and not self.key_fields:
            raise ContractError(f"{self.name}: idempotent tools must declare key_fields")
        # H5
        if self.effect == WRITE and not self.idempotent and not self.reconcile_with:
            raise ContractError(
                f"{self.name}: a write with no retry must declare reconcile_with"
            )

    def attempts_after_timeout(self) -> int:
        """H1. Unknown is not failure. Retrying a write we cannot dedupe is how
        one filing becomes two."""
        return self.max_attempts if self.idempotent else 1


def canonical(obj: Any) -> str:
    return json.dumps(obj, sort_keys=True, separators=(",", ":"), default=str)


def idempotency_key(spec: ToolSpec, run_id: str, args: Mapping[str, Any]) -> str:
    """H2. Derived, never generated. Two attempts at the same call inside one
    run produce the same key; the same call in a new run does not."""
    missing = [f for f in spec.key_fields if f not in args]
    if missing:
        raise ContractError(f"{spec.name}: key fields absent from args: {missing}")
    material = canonical(
        {
            "run": run_id,
            "tool": spec.name,
            "v": spec.version,
            "key": {f: args[f] for f in spec.key_fields},
        }
    )
    return hashlib.sha256(material.encode()).hexdigest()[:24]


def load_registry(doc: Mapping[str, Any]) -> dict[str, ToolSpec]:
    out: dict[str, ToolSpec] = {}
    for name, d in doc["tools"].items():
        out[name] = ToolSpec(
            name=name,
            version=d["version"],
            effect=d["effect"],
            timeout_s=d["timeout_s"],
            max_attempts=d.get("max_attempts", 1),
            idempotent=d.get("idempotent", False),
            key_fields=tuple(d.get("key_fields", ())),
            compensating_action=d.get("compensating_action"),
            reconcile_with=d.get("reconcile_with"),
            requires_approval=d.get("requires_approval", False),
        )
    return out

harness/run.py — the ledger, the effect gate, and replay Python 
"""harness/run.py — the ledger, the effect gate, and replay.

The loop is a fold over an append-only ledger, not a `while True`. That is the
whole architectural choice on this page, and every invariant below depends on
it.

  H5  Every step appends exactly one intent event before its effect and
      exactly one outcome event after. There is no third path out.
  H6  Replay never executes an effect. Effects are served from the ledger.
  H7  Replay does not re-run the model either. It re-runs *our code* against
      what the model said. Replay validates the reasoning around the model,
      not the model.
  H8  An irreversible effect is refused unless an approval event for that
      exact idempotency key already sits in the ledger.
"""
from __future__ import annotations

import json
from dataclasses import dataclass, field
from typing import Any, Callable, Mapping

from contract import (
    IRREVERSIBLE,
    ContractError,
    ToolSpec,
    canonical,
    idempotency_key,
)


class ToolTimeout(Exception):
    pass


class ApprovalRequired(Exception):
    pass


class Escalate(Exception):
    def __init__(self, reason: str, detail: Mapping[str, Any]):
        super().__init__(reason)
        self.reason = reason
        self.detail = dict(detail)


@dataclass
class Ledger:
    run_id: str
    events: list[dict] = field(default_factory=list)

    def append(self, kind: str, **payload: Any) -> dict:
        ev = {"seq": len(self.events), "run": self.run_id, "kind": kind, **payload}
        self.events.append(ev)
        return ev

    def find(self, kind: str, **match: Any) -> dict | None:
        for ev in self.events:
            if ev["kind"] == kind and all(ev.get(k) == v for k, v in match.items()):
                return ev
        return None

    DECISIVE = ("model_observed", "tool_observed", "tool_unknown",
                "effect_refused", "escalated", "run_ended")

    def decision_digest(self) -> str:
        """What the run decided, with the mechanics of *how* it got there left
        out. A replay ledger is not byte-identical to the live one - it has no
        timeouts in it and every observation is marked `source=ledger`. This is
        the thing that has to match."""
        import hashlib

        material = canonical(
            [
                {k: v for k, v in ev.items()
                 if k not in ("seq", "source", "attempt", "budget")}
                for ev in self.events if ev["kind"] in self.DECISIVE
            ]
        )
        return hashlib.sha256(material.encode()).hexdigest()[:16]


class Harness:
    def __init__(
        self,
        run_id: str,
        registry: Mapping[str, ToolSpec],
        transport: Callable[[str, Mapping[str, Any], float, int], Any] | None = None,
        prior: Ledger | None = None,
    ):
        self.registry = registry
        self.replaying = prior is not None
        self.prior = prior
        self.transport = transport
        self.ledger = Ledger(run_id=run_id)
        self.ledger.append("run_started", mode="replay" if self.replaying else "live")

    # ── model step ────────────────────────────────────────────────
    def model(self, step: str, fn: Callable[[], Any]) -> Any:
        if self.replaying:  # H7
            prior = self.prior.find("model_observed", step=step)
            if prior is None:
                raise Escalate("replay_gap", {"step": step})
            self.ledger.append("model_observed", step=step, output=prior["output"],
                               source="ledger")
            return prior["output"]
        out = fn()
        self.ledger.append("model_observed", step=step, output=out, source="live")
        return out

    # ── tool step ─────────────────────────────────────────────────
    def call(self, tool: str, step: str, **args: Any) -> Any:
        spec = self.registry[tool]
        key = idempotency_key(spec, self.ledger.run_id, args) if spec.idempotent else None

        # H8 — approval is checked before the intent event, not after.
        if spec.effect == IRREVERSIBLE:
            approval = (self.prior or self.ledger).find("approval_recorded", step=step)
            if approval is None:
                self.ledger.append("effect_refused", step=step, tool=tool,
                                   reason="no_approval_on_ledger")
                raise ApprovalRequired(f"{tool} at {step}")

        self.ledger.append("tool_attempted", step=step, tool=tool, key=key,
                           effect=spec.effect, budget=spec.attempts_after_timeout())

        if self.replaying:  # H6
            prior = self.prior.find("tool_observed", step=step)
            if prior is not None:
                self.ledger.append("tool_observed", step=step, tool=tool,
                                   result=prior["result"], attempt=prior["attempt"],
                                   source="ledger")
                return prior["result"]
            unknown = self.prior.find("tool_unknown", step=step)
            if unknown is not None:
                self.ledger.append("tool_unknown", step=step, tool=tool,
                                   attempts=unknown["attempts"],
                                   reconcile_with=unknown["reconcile_with"],
                                   source="ledger")
                raise ToolTimeout(f"{tool} at {step} (replayed as unknown)")
            raise Escalate("replay_gap", {"step": step})

        budget = spec.attempts_after_timeout()  # H1
        for attempt in range(1, budget + 1):
            try:
                result = self.transport(tool, args, spec.timeout_s, attempt)
            except ToolTimeout:
                self.ledger.append("tool_timeout", step=step, tool=tool,
                                   attempt=attempt, of=budget, key=key)
                continue
            self.ledger.append("tool_observed", step=step, tool=tool,
                               result=result, attempt=attempt)
            return result

        # H5. Unknown, with the one instruction that makes unknown actionable.
        self.ledger.append("tool_unknown", step=step, tool=tool, attempts=budget,
                           reconcile_with=spec.reconcile_with)
        raise ToolTimeout(f"{tool} at {step}")

    def escalate(self, reason: str, **detail: Any) -> None:
        self.ledger.append("escalated", reason=reason, **detail)

    def end(self, outcome: str) -> None:
        self.ledger.append("run_ended", outcome=outcome)
harness/demo.py — the workflow and a scripted transport, so the trace below reproduces Python 
"""The worked run. A scripted transport, so every line below reproduces.

Drop contract.py, run.py and registry.v2.json alongside this file and run
`python demo.py`. The output is what is printed on the page.
"""
import json, textwrap
from contract import load_registry, ContractError
from run import Harness, Ledger, ToolTimeout, ApprovalRequired, Escalate

REG = load_registry(json.load(open('registry.v2.json')))

# Fault script: (tool, attempt) -> "timeout" | value
FAULTS = {
    ('policy.lookup', 1): 'timeout',
    ('queue.assign_reviewer', 1): 'timeout',
}

def transport(tool, args, timeout_s, attempt):
    if FAULTS.get((tool, attempt)) == 'timeout':
        raise ToolTimeout(tool)
    if tool == 'policy.lookup':
        return {'control_id': args['control_id'], 'owner': 'FinCrime-2', 'tier': 'T2'}
    if tool == 'case.attach_assessment':
        return {'attached': True, 'case_id': args['case_id']}
    if tool == 'queue.assign_reviewer':
        return {'assignment_id': 'A-90311'}
    raise AssertionError(tool)

MODEL_OUTPUT = {
    'control_id': 'C-118',
    'impact': 'material',
    'confidence': 0.71,
    'citations': ['POL-2024.3 §4.2'],
}

def workflow(h):
    """Same function for the live run and the replay. That is the point."""
    pol = h.call('policy.lookup', step='s1', control_id='C-118', policy_version='2024.3')
    out = h.model('s2', lambda: MODEL_OUTPUT)
    h.call('case.attach_assessment', step='s3',
           case_id='CASE-4471', assessment_hash='9f2c1e')
    try:
        h.call('queue.assign_reviewer', step='s4',
               case_id='CASE-4471', owner=pol['owner'])
    except ToolTimeout:
        h.escalate('assignment_unknown', step='s4',
                   note='non-idempotent write timed out; not retried (H1)')
        h.end('escalated_to_human')
        return 'escalated_to_human'
    h.end('completed')
    return 'completed'

def render(led, title):
    print(f'\n{title}')
    print('-' * len(title))
    for ev in led.events:
        p = {k: v for k, v in ev.items() if k not in ('seq', 'run', 'kind')}
        line = f"{ev['seq']:>3}  {ev['kind']:<16} " + '  '.join(
            f'{k}={json.dumps(v, ensure_ascii=False) if isinstance(v,(dict,list)) else v}' for k, v in p.items())
        print(textwrap.fill(line, 96, subsequent_indent=' ' * 21))
    print(f'     decision_digest = {led.decision_digest()}')

# ── 1. live run ───────────────────────────────────────────────────
live = Harness('run_7', REG, transport=transport)
r1 = workflow(live)
render(live.ledger, f'LIVE RUN run_7 -> {r1}')

# ── 2. replay of that run ─────────────────────────────────────────
class Tripwire:
    def __call__(self, *a, **k):
        raise AssertionError('replay executed an effect')

rep = Harness('run_7', REG, transport=Tripwire(), prior=live.ledger)
r2 = workflow(rep)
render(rep.ledger, f'REPLAY run_7 -> {r2}')

def decisions(led):
    return [(e['kind'], e.get('step'), e.get('result') or e.get('output'))
            for e in led.events
            if e['kind'] in ('tool_observed', 'model_observed', 'tool_unknown', 'escalated')]

print('\nreplay reproduced the decision path :', decisions(live.ledger) == decisions(rep.ledger))
print('decision_digest live == replay      :',
      live.ledger.decision_digest() == rep.ledger.decision_digest())
print('effects executed during replay      : 0  (the transport raises if called)')

# ── 3. irreversible without approval ──────────────────────────────
h3 = Harness('run_8', REG, transport=transport)
try:
    h3.call('regulator.file_report', step='f1', case_id='CASE-4471')
except ApprovalRequired as e:
    print(f'\nregulator.file_report refused       : {e}')
render(h3.ledger, 'RUN run_8 -> refused')

# ── 4. the contract refuses to load a bad tool ────────────────────
print()
for bad in [
    {'tools': {'x.send': {'version':'1', 'effect':'irreversible', 'timeout_s':5,
                          'max_attempts':1, 'requires_approval': True}}},
    {'tools': {'z.assign': {'version':'1', 'effect':'write', 'timeout_s':5,
                            'max_attempts':1, 'idempotent': False}}},
    {'tools': {'y.write': {'version':'1', 'effect':'write', 'timeout_s':5,
                           'max_attempts':3, 'idempotent': False}}},
]:
    try:
        load_registry(bad)
        print('LOADED (should not happen)')
    except ContractError as e:
        print('registry rejected                   :', e)

What this doesn't do

Five invariants bought some things and charged for others. Here's the bill.

  • Replay doesn't re-run the model, so it can't tell you the model would say the same thing today. It tells you your code would do the same thing with what the model said. That's the smaller of the two questions, and it's the one I can actually answer.
  • The ledger roughly doubles write volume on every run, and it is the first line item someone proposes trimming in month four. I'd rather sample which runs carry a full ledger than thin the ledger on every run, but that is an argument, not a settled fact.
  • Refusing to retry a write we can't dedupe converts a machine problem into a human one. reconcile_with is what stops that being a cop-out — and it only works if somebody is genuinely on the other end of the escalation.
  • Owning the harness costs you the ecosystem: the integrations, the traces someone else already debugged, the examples your next hire has already read. On a small team with no audit requirement, I would not make this trade.
  • None of this makes the model better. It bounds what a wrong answer is allowed to do. If the accuracy isn't there, a harness just makes the failures easier to read.
