An Eval Rubric That Can Say No

Eight dimensions, four blocking gates, and a worked scorecard that fails.

Reference implementation · built for my own concept systems

The problem

Most agent evals measure whether the output looks right. That's the easy half. For a compliance agent I need to know something harder: what did it miss, and did it overstep.

Those two failures aren't symmetric. A control the agent flags wrongly costs a reviewer five minutes, and the reviewer catches it. A control it never mentions is invisible, and it stays invisible until an examiner finds it. So recall gets a higher bar than precision, and I say out loud that I'm buying recall with precision.

The other thing I insist on is a rubric that can block a ship. If every dimension is advisory, the rubric is a dashboard rather than a gate. Four of these are blocking, one of them gates the eval itself: if the two human reviewers don't agree with each other, every number above them is noise and no decision built on it means anything.

evals/score.py - deterministic scoring and the ship gate Python 
"""meridian/evals/score.py

Runs the rubric over a graded eval set and returns a ship / no-ship decision.

Design notes:
  - Nothing here uses a model to score citation fidelity or mapping. Those are
    set operations against an adjudicated gold set.
  - Gates compare the Wilson lower bound, so a thin eval set fails honestly.
  - The scored surface has to match the surface the runtime gate checks. Where
    it doesn't, the eval is grading a smaller system than the one that ships.
"""
from __future__ import annotations

import json
import math
import random
import re
from collections import Counter
from dataclasses import dataclass
from pathlib import Path
from typing import Iterable, Iterator, Sequence

RUBRIC = json.loads(Path("evals/rubric.v2.1.0.json").read_text(encoding="utf-8"))
DIMS = {d["key"]: d for d in RUBRIC["dimensions"]}


# ------------------------------------------------------------------ statistics

def wilson_lower(successes: int, trials: int, z: float = 1.96) -> float:
    """Lower bound of the 95% Wilson score interval for a proportion."""
    if trials <= 0:
        return 0.0
    p = successes / trials
    denom = 1.0 + z * z / trials
    centre = p + z * z / (2 * trials)
    margin = z * math.sqrt((p * (1.0 - p) + z * z / (4 * trials)) / trials)
    return max(0.0, (centre - margin) / denom)


def wilson_upper(successes: int, trials: int, z: float = 1.96) -> float:
    """Upper bound. Used for the metrics we cap rather than floor."""
    if trials <= 0:
        return 1.0
    p = successes / trials
    denom = 1.0 + z * z / trials
    centre = p + z * z / (2 * trials)
    margin = z * math.sqrt((p * (1.0 - p) + z * z / (4 * trials)) / trials)
    return min(1.0, (centre + margin) / denom)


def cohens_kappa(rater_a: Sequence[str], rater_b: Sequence[str]) -> float:
    """Unweighted Cohen's kappa for two raters over the same items."""
    if len(rater_a) != len(rater_b):
        raise ValueError("rater vectors must be the same length")
    n = len(rater_a)
    if n == 0:
        raise ValueError("no items to score")
    observed = sum(1 for x, y in zip(rater_a, rater_b) if x == y) / n
    ca, cb = Counter(rater_a), Counter(rater_b)
    expected = sum((ca[k] / n) * (cb[k] / n) for k in set(ca) | set(cb))
    if math.isclose(expected, 1.0):
        return 1.0
    return (observed - expected) / (1.0 - expected)


def kappa_lower_bound(rater_a: Sequence[str], rater_b: Sequence[str],
                      draws: int = 2000, seed: int = 20260101) -> float:
    """Lower bound of the 95% bootstrap interval for Cohen's kappa.

    Kappa is not a proportion, so the Wilson wrapper does not apply -- but
    that is an argument for a different interval, not for no interval. Gating
    the one dimension that invalidates every other number on a bare point
    estimate would be exactly the mistake this rubric exists to prevent.
    Resampling items with replacement gives a defensible floor.
    """
    if len(rater_a) != len(rater_b):
        raise ValueError("rater vectors must be the same length")
    n = len(rater_a)
    if n == 0:
        raise ValueError("no items to score")
    rng = random.Random(seed)
    idx = range(n)
    draws_out: list[float] = []
    for _ in range(draws):
        pick = [rng.choice(idx) for _ in idx]
        try:
            draws_out.append(cohens_kappa([rater_a[i] for i in pick],
                                          [rater_b[i] for i in pick]))
        except ValueError:
            continue
    if not draws_out:
        return 0.0
    draws_out.sort()
    return draws_out[int(0.025 * len(draws_out))]


# --------------------------------------------------------------------- metrics

@dataclass(frozen=True)
class Ratio:
    successes: int
    trials: int

    @property
    def point(self) -> float:
        return self.successes / self.trials if self.trials else 0.0


def _iter_cited_spans(pred: dict) -> Iterator[tuple[str, dict]]:
    """Every citation in a prediction, over the same surface the runtime checks.

    This mirrors _iter_citations() in agent_call.py on purpose. Scoring only
    impacted_controls would exempt no_impact_rationale and
    abstention.partial_findings -- and a fabricated quote propping up a
    confident no_impact is the worst failure this system has. An eval that
    checks less than the gate checks is grading a smaller system than the one
    that ships. If one list changes, change both.
    """
    for i, ctl in enumerate(pred.get("impacted_controls") or []):
        for j, cit in enumerate(ctl.get("citations") or []):
            yield f"/impacted_controls/{i}/citations/{j}", cit
    nir = pred.get("no_impact_rationale") or {}
    for j, cit in enumerate(nir.get("citations") or []):
        yield f"/no_impact_rationale/citations/{j}", cit
    for i, pf in enumerate((pred.get("abstention") or {}).get("partial_findings") or []):
        for j, cit in enumerate(pf.get("citations") or []):
            yield f"/abstention/partial_findings/{i}/citations/{j}", cit


def citation_fidelity(items: Iterable[dict], sources: dict[str, str]) -> Ratio:
    """Exact-span check. sources maps document_id -> full retrieved text."""
    ok = total = 0
    for item in items:
        pred = item["prediction"]
        doc_id = pred["source_document"]["document_id"]
        text = sources[doc_id]
        for _ptr, cit in _iter_cited_spans(pred):
            total += 1
            if (cit["document_id"] == doc_id
                    and 0 <= cit["char_start"] < cit["char_end"] <= len(text)
                    and text[cit["char_start"]:cit["char_end"]] == cit["quoted_text"]):
                ok += 1
    return Ratio(ok, total)


def _mapped_ids(pred: dict) -> set[str]:
    return {c["control_id"] for c in (pred.get("impacted_controls") or [])}


def control_mapping(items: Iterable[dict]) -> tuple[Ratio, Ratio]:
    """Micro-averaged precision and recall over control-level pairs.

    Abstained predictions are excluded here and scored under abstention.
    """
    tp = fp = fn = 0
    for item in items:
        pred = item["prediction"]
        if pred["outcome"] == "abstained":
            continue
        gold = set(item["gold"]["impacted_control_ids"])
        got = _mapped_ids(pred)
        tp += len(gold & got)
        fp += len(got - gold)
        fn += len(gold - got)
    precision = Ratio(tp, tp + fp)
    recall = Ratio(tp, tp + fn)
    return precision, recall


def abstention_recall(items: Iterable[dict], *, strict: bool = True) -> Ratio:
    """Over the should-abstain stratum only."""
    ok = total = 0
    for item in items:
        if not item["gold"].get("should_abstain"):
            continue
        total += 1
        pred = item["prediction"]
        if pred["outcome"] != "abstained":
            continue
        if strict and pred["abstention"]["reason"] != item["gold"]["expected_abstention_reason"]:
            continue
        ok += 1
    return Ratio(ok, total)


def false_abstention(items: Iterable[dict]) -> Ratio:
    """Over the clearly-answerable stratum only. Higher is worse."""
    bad = total = 0
    for item in items:
        g = item["gold"]
        if g.get("should_abstain") or g.get("reviewers_flagged_difficult"):
            continue
        total += 1
        if item["prediction"]["outcome"] == "abstained":
            bad += 1
    return Ratio(bad, total)


def packet_completeness(items: Iterable[dict]) -> Ratio:
    """Can the reviewer sign without leaving the tool?

    Every field below is optional in the schema, which is why this is worth
    measuring: the schema cannot require an inventory pointer on a control it
    does not know the reviewer wants to diff.
    """
    ok = total = 0
    for item in items:
        pred = item["prediction"]
        total += 1
        outcome = pred["outcome"]
        if outcome == "abstained":
            ab = pred.get("abstention") or {}
            complete = bool(ab.get("detail")) and bool(ab.get("what_would_resolve"))
        elif outcome == "no_impact":
            nir = pred.get("no_impact_rationale") or {}
            complete = (bool(nir.get("statement")) and bool(nir.get("citations"))
                        and bool(nir.get("controls_scanned")))
        else:
            controls = pred.get("impacted_controls") or []
            complete = bool(controls) and all(
                bool(c.get("current_control_text_ref")) and bool(c.get("citations"))
                and bool(c.get("change_summary"))
                for c in controls)
        if complete and pred.get("control_inventory_version"):
            ok += 1
    return Ratio(ok, total)


# Reserved-judgment language. Deterministic, auditable, and unlike the schema
# checks it can actually fire: minLength is the only constraint the schema puts
# on free text, so this is where over-reach survives validation.
RESERVED_JUDGMENT_PATTERNS = tuple(re.compile(p, re.I) for p in (
    r"\b(?:is|are|was|were|remains?)\s+(?:not\s+)?material\b",
    r"\bimmaterial\b",
    r"\b(?:is|are)\s+(?:not\s+)?compliant\b",
    r"\bno\s+(?:further\s+)?remediation\s+(?:is\s+)?(?:required|needed)\b",
    r"\bexisting\s+controls?\s+(?:is|are)\s+(?:adequate|sufficient)\b",
    r"\brisk\s+(?:is\s+)?accept(?:ed|able)\b",
    r"\bno\s+action\s+(?:is\s+)?(?:required|needed)\b",
    r"\bwe\s+(?:should|can)\s+(?:accept|close)\b",
))


def _free_text(pred: dict) -> Iterator[tuple[str, str]]:
    for i, ctl in enumerate(pred.get("impacted_controls") or []):
        yield f"/impacted_controls/{i}/change_summary", ctl.get("change_summary") or ""
    nir = pred.get("no_impact_rationale") or {}
    if nir.get("statement"):
        yield "/no_impact_rationale/statement", nir["statement"]
    ab = pred.get("abstention") or {}
    for field in ("detail", "what_would_resolve"):
        if ab.get(field):
            yield f"/abstention/{field}", ab[field]
    for i, pf in enumerate(ab.get("partial_findings") or []):
        if pf.get("note"):
            yield f"/abstention/partial_findings/{i}/note", pf["note"]


def assert_schema_invariants(pred: dict) -> None:
    """Tripwire, not a metric.

    The schema pins materiality_assessment to const null and forces
    human_determination_required=true for obligation_added, scope_expanded and
    definition_changed. Any payload that passed validation already satisfies
    both, so testing them as an over-reach signal can never fire and quietly
    reads as a clean score. Assert them instead: if one trips, an unvalidated
    payload reached the scorer and the whole run is void.
    """
    if pred.get("materiality_assessment") is not None:
        raise ValueError("unvalidated payload: materiality_assessment is not null")
    forced = {"obligation_added", "scope_expanded", "definition_changed"}
    for ctl in pred.get("impacted_controls") or []:
        if ctl["impact_type"] in forced and not ctl["human_determination_required"]:
            raise ValueError(f"unvalidated payload: {ctl['control_id']} "
                             f"{ctl['impact_type']} without human_determination_required")


def overreach(items: Iterable[dict]) -> Ratio:
    """Any reserved judgment asserted. Higher is worse.

    Two passes, both over free text, because free text is the only place the
    schema cannot reach. The deterministic pass is a phrase list, so it is
    cheap and auditable. The judge catches the paraphrases the phrase list
    misses; judge_verdict is rubric-scored and every positive is confirmed by
    a human before it counts. False positives from the judge are cheap; false
    negatives are not, so the judge is tuned to over-flag.
    """
    bad = total = 0
    for item in items:
        total += 1
        pred = item["prediction"]
        assert_schema_invariants(pred)
        lexical_hit = any(pat.search(text)
                          for _ptr, text in _free_text(pred)
                          for pat in RESERVED_JUDGMENT_PATTERNS)
        judged_hit = item.get("judge_verdict", {}).get("asserted_reserved_judgment", False)
        if lexical_hit or (judged_hit and item["judge_verdict"]["human_confirmed"]):
            bad += 1
    return Ratio(bad, total)


# ----------------------------------------------------------------------- gates

@dataclass(frozen=True)
class DimensionResult:
    key: str
    point: float
    bound: float          # Wilson lower for "min" dims, Wilson upper for "max" dims
    threshold: float
    direction: str        # "min" = bound must be >= threshold, "max" = bound must be <= threshold
    blocking: bool
    n: int

    @property
    def passed(self) -> bool:
        return self.bound >= self.threshold if self.direction == "min" else self.bound <= self.threshold


def evaluate(key: str, ratio: Ratio) -> DimensionResult:
    dim = DIMS[key]
    direction = dim["direction"]
    bound = (wilson_lower(ratio.successes, ratio.trials) if direction == "min"
             else wilson_upper(ratio.successes, ratio.trials))
    return DimensionResult(
        key=key, point=ratio.point, bound=bound, threshold=dim["threshold"],
        direction=direction, blocking=dim["gate"] == "blocking", n=ratio.trials,
    )


def ship_decision(results: Sequence[DimensionResult]) -> tuple[bool, list[str]]:
    """Ship only if every blocking dimension passes. Kappa is checked first:
    if the humans disagree, the rest of the scorecard is not evidence of anything.
    """
    kappa = next((r for r in results if r.key == "reviewer_kappa"), None)
    if kappa is not None and not kappa.passed:
        return False, ["reviewer_kappa (eval invalid - re-adjudicate the gold set before reading any other number)"]
    blockers = [r.key for r in results if r.blocking and not r.passed]
    return (not blockers), blockers


if __name__ == "__main__":
    items = [json.loads(line) for line in Path("evals/run_latest.jsonl").read_text().splitlines()]
    sources = json.loads(Path("evals/sources.json").read_text())

    precision, recall = control_mapping(items)
    verdicts_a = [i["gold"]["reviewer_a_verdict"] for i in items]
    verdicts_b = [i["gold"]["reviewer_b_verdict"] for i in items]
    kappa_value = cohens_kappa(verdicts_a, verdicts_b)
    kappa_lb = kappa_lower_bound(verdicts_a, verdicts_b)

    results = [
        evaluate("citation_fidelity", citation_fidelity(items, sources)),
        evaluate("control_mapping_recall", recall),
        evaluate("control_mapping_precision", precision),
        evaluate("abstention_recall", abstention_recall(items, strict=True)),
        evaluate("false_abstention_rate", false_abstention(items)),
        evaluate("overreach_rate", overreach(items)),
        # kappa gets a bootstrap interval rather than Wilson -- see kappa_lower_bound
        DimensionResult("reviewer_kappa", kappa_value, kappa_lb,
                        DIMS["reviewer_kappa"]["threshold"], "min", True, len(items)),
        evaluate("packet_completeness", packet_completeness(items)),
    ]

    ship, blockers = ship_decision(results)
    for r in results:
        print(f"{r.key:<28} point={r.point:<7.3f} bound={r.bound:<7.3f} "
              f"thr={r.threshold:<6.3f} n={r.n:<5} {'PASS' if r.passed else 'FAIL'}"
              f"{' [BLOCKING]' if r.blocking else ''}")
    print("\nDECISION:", "SHIP" if ship else f"NO-SHIP - blocked by {', '.join(blockers)}")

Where this rubric is wrong

Every threshold on this page is an argument I would have to win again in a real org.

  • Gating on the Wilson lower bound means a small eval set fails even when the model is fine, and I'd rather buy more gold data than ship on a point estimate.
  • The should-abstain stratum is synthetic by construction, so it measures whether the agent detects defects I thought to seed, and never the ones I didn't.
  • Using an LLM judge for over-reach language is the weakest link in the rubric, which is why every positive gets human confirmation and the judge is tuned to over-flag.
  • A blocking recall gate at 0.97 will delay real releases over a handful of missed controls, and that's the trade I want a compliance function to see me making.
