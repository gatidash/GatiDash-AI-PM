The Validated Agent Call

Schema-gated output, a bounded repair loop, and abstention as a real answer.

Reference implementation · built for my own concept systems

The problem

A model that returns prose is a demo. A model that returns a validated object is a component you can build on. Meridian's whole job is to hand a compliance officer a packet they can sign. So the unit of work is a `control_impact_assessment` that either conforms or doesn't exist. A paragraph won't do.

Two things go wrong in practice. The model produces something almost-valid and downstream code quietly coerces it. Or it can't do the task and invents a citation to fill a required field, because the schema demanded one and nothing offered it a way out. Both failures look like success in the logs.

So I fix it in two places. The schema makes `abstained` a legitimate outcome with its own required fields, so refusing is a well-formed answer rather than an error. And the repair loop has a hard budget: two retries, each naming the exact violation, then it stops and hands the thing to a person. Retrying forever is how you turn a 30-second failure into a four-minute one and still get nothing.

meridian/agent_call.py - validate, repair, escalate Python 
"""meridian/agent_call.py

One schema-gated model call, with a bounded repair loop.

Contract, in order of importance:
  1. This function always returns. There is no branch that returns None.
  2. It never returns a payload that failed validation.
  3. A payload that cannot be repaired inside the budget becomes a human
     task, not a dropped record.
"""
from __future__ import annotations

import json
import time
import uuid
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Callable, Literal, Sequence

from jsonschema import Draft202012Validator

SCHEMA_PATH = Path(__file__).parent / "schemas" / "control_impact_assessment.v1.4.0.json"
SCHEMA: dict[str, Any] = json.loads(SCHEMA_PATH.read_text(encoding="utf-8"))
VALIDATOR = Draft202012Validator(SCHEMA)

MAX_REPAIRS = 2                 # repairs after the first call, so at most 3 model calls
MAX_VIOLATIONS_IN_PROMPT = 5    # a repair prompt with 40 bullet points repairs nothing
CONFIDENCE_FLOOR = 0.72         # ILLUSTRATIVE. Set from the calibration curve, not by taste.


# ----------------------------------------------------------------------------- types

@dataclass(frozen=True)
class Violation:
    pointer: str      # RFC 6901 pointer to the offending node, "" for the root
    constraint: str   # the schema keyword (or semantic check) that failed
    expected: str
    got: str

    def render(self) -> str:
        return (f"- at `{self.pointer or '/'}`: failed `{self.constraint}`. "
                f"Expected {self.expected}. Got {self.got}.")


@dataclass(frozen=True)
class Accepted:
    payload: dict
    attempts_used: int
    retry_budget_remaining: int
    trace_id: str


@dataclass(frozen=True)
class Escalation:
    reason: Literal["unparseable_output", "schema_unrecoverable", "span_integrity_failed"]
    trace_id: str
    attempts_used: int
    violations: list[Violation]
    last_raw_output: str
    route_to: str = "compliance_queue.tier_2"   # see the escalation matrix


Result = Accepted | Escalation


# ------------------------------------------------------------------------- checking

def _pointer(path: Sequence[Any]) -> str:
    return "".join("/" + str(p) for p in path)


def _short(value: Any, limit: int = 120) -> str:
    text = json.dumps(value, ensure_ascii=False, default=str)
    return text if len(text) <= limit else text[: limit - 1] + "..."


def collect_schema_violations(payload: dict) -> list[Violation]:
    """Every schema failure, ordered by path, deduplicated by (pointer, keyword)."""
    seen: set[tuple[str, str]] = set()
    out: list[Violation] = []
    for err in sorted(VALIDATOR.iter_errors(payload), key=lambda e: list(map(str, e.absolute_path))):
        key = (_pointer(err.absolute_path), str(err.validator))
        if key in seen:
            continue
        seen.add(key)
        out.append(Violation(
            pointer=_pointer(err.absolute_path),
            constraint=str(err.validator),
            expected=_short(err.validator_value),
            got=_short(err.instance),
        ))
    return out


def _iter_citations(payload: dict):
    """Yield (pointer, citation) for every citation anywhere in the payload."""
    for i, ctl in enumerate(payload.get("impacted_controls") or []):
        for j, cit in enumerate(ctl.get("citations") or []):
            yield f"/impacted_controls/{i}/citations/{j}", cit
    nir = payload.get("no_impact_rationale") or {}
    for j, cit in enumerate(nir.get("citations") or []):
        yield f"/no_impact_rationale/citations/{j}", cit
    for i, pf in enumerate((payload.get("abstention") or {}).get("partial_findings") or []):
        for j, cit in enumerate(pf.get("citations") or []):
            yield f"/abstention/partial_findings/{i}/citations/{j}", cit


def collect_span_violations(payload: dict, source_text: str) -> list[Violation]:
    """JSON Schema cannot compare two fields, and it has never seen the source document.

    Run this only after the schema passes, so every key below is guaranteed present.
    """
    out: list[Violation] = []
    doc_len = len(source_text)
    doc_id = payload["source_document"]["document_id"]

    for ptr, cit in _iter_citations(payload):
        if cit["document_id"] != doc_id:
            out.append(Violation(ptr + "/document_id", "citation_provenance",
                                 f"the assessed document {doc_id}", cit["document_id"]))
            continue
        start, end = cit["char_start"], cit["char_end"]
        if end <= start:
            out.append(Violation(ptr, "span_order", "char_end > char_start", f"{start}..{end}"))
            continue
        if end > doc_len:
            out.append(Violation(ptr, "span_bounds", f"char_end <= {doc_len}", str(end)))
            continue
        actual = source_text[start:end]
        if actual != cit["quoted_text"]:
            out.append(Violation(ptr + "/quoted_text", "span_fidelity",
                                 "an exact slice of source_document[char_start:char_end]",
                                 _short(actual, 80) + " (paraphrase or offset drift)"))
    return out


# --------------------------------------------------------------------- repair prompt

REPAIR_TEMPLATE = """Your previous output was rejected by the validator. It never reached a human.

It is not valid against `control_impact_assessment` v{schema_version}.

Violations ({shown} of {total}):
{violations}

Fix exactly those. These rules still hold:

1. Every claim carries a citation with character offsets into the source document.
   `quoted_text` must be an exact slice of source_document[char_start:char_end].
   A paraphrase inside quote marks fails the check.
2. Do not invent a control id to fill a required field. `impacted_controls` may only
   contain ids from the inventory ({inventory}) you were given.
3. `materiality_assessment` stays null. That call belongs to the compliance officer.
4. If you cannot satisfy these rules with the evidence in front of you, return
   `"outcome": "abstained"` with an `abstention.reason` and `abstention.what_would_resolve`,
   and put whatever you did establish into `abstention.partial_findings`.
   Abstaining is a correct answer. It is scored as one.

Return the corrected JSON object only. No prose. No code fences.
Repair attempts remaining after this one: {budget_after}."""


def build_repair_prompt(violations: list[Violation], *, inventory: str, budget_after: int) -> str:
    shown = violations[:MAX_VIOLATIONS_IN_PROMPT]
    return REPAIR_TEMPLATE.format(
        schema_version=SCHEMA["properties"]["schema_version"]["const"],
        shown=len(shown),
        total=len(violations),
        violations="\n".join(v.render() for v in shown),
        inventory=inventory,
        budget_after=budget_after,
    )


# ------------------------------------------------------------------------- the call

def assess_control_impact(
    *,
    source_text: str,
    inventory_version: str,
    initial_messages: list[dict],
    call_model: Callable[[list[dict]], str],
    audit: Callable[..., None],
    max_repairs: int = MAX_REPAIRS,
) -> Result:
    trace_id = "trace_" + uuid.uuid4().hex[:12]
    messages = list(initial_messages)
    budget = max_repairs
    violations: list[Violation] = []
    raw = ""

    for attempt in range(1, max_repairs + 2):      # one initial call, then the repairs
        started = time.monotonic()
        raw = call_model(messages)
        latency_ms = int((time.monotonic() - started) * 1000)

        payload: dict | None
        try:
            payload = json.loads(raw)
        except json.JSONDecodeError as exc:
            payload = None
            violations = [Violation("", "json_parse", "one JSON object",
                                    f"{exc.msg} at char {exc.pos}")]
        else:
            if not isinstance(payload, dict):
                violations = [Violation("", "type", "object", _short(payload))]
            else:
                violations = collect_schema_violations(payload)
                if not violations:
                    violations = collect_span_violations(payload, source_text)

        audit(
            "agent.assessment.attempt",
            trace_id=trace_id,
            attempt=attempt,
            max_attempts=max_repairs + 1,
            retry_budget_remaining=budget,
            latency_ms=latency_ms,
            result="accepted" if not violations else "rejected",
            violation_count=len(violations),
            violation_pointers=[v.pointer for v in violations[:MAX_VIOLATIONS_IN_PROMPT]],
        )

        if not violations:
            assert isinstance(payload, dict)
            if payload["outcome"] != "abstained" and payload["confidence"]["value"] < CONFIDENCE_FLOOR:
                # Not a schema failure. A routing fact. The matrix bumps this a tier.
                audit("agent.assessment.below_confidence_floor",
                      trace_id=trace_id,
                      confidence=payload["confidence"]["value"],
                      floor=CONFIDENCE_FLOOR)
            audit("agent.assessment.accepted",
                  trace_id=trace_id,
                  outcome=payload["outcome"],
                  attempts_used=attempt,
                  retry_budget_consumed=max_repairs - budget,
                  retry_budget_remaining=budget)
            return Accepted(payload=payload, attempts_used=attempt,
                            retry_budget_remaining=budget, trace_id=trace_id)

        if budget == 0:
            break                                   # budget spent, stop repairing

        budget -= 1
        messages = messages + [
            {"role": "assistant", "content": raw},
            {"role": "user", "content": build_repair_prompt(
                violations, inventory=inventory_version, budget_after=budget)},
        ]

    reason: Literal["unparseable_output", "schema_unrecoverable", "span_integrity_failed"]
    if violations and violations[0].constraint == "json_parse":
        reason = "unparseable_output"
    elif violations and violations[0].constraint.startswith("span_"):
        reason = "span_integrity_failed"
    else:
        reason = "schema_unrecoverable"

    audit("agent.assessment.escalated",
          trace_id=trace_id,
          reason=reason,
          attempts_used=max_repairs + 1,
          retry_budget_remaining=0,
          violation_pointers=[v.pointer for v in violations],
          route_to="compliance_queue.tier_2")

    # The failure leaves here as a queued human task. Nothing is dropped, and
    # nothing half-valid is handed to a reviewer as if it were finished work.
    return Escalation(reason=reason, trace_id=trace_id, attempts_used=max_repairs + 1,
                      violations=violations, last_raw_output=raw[:4000])

What this costs

A strict schema buys determinism and charges for it. Here is the bill.

  • A strict schema plus span verification rejects some genuinely good outputs on a technicality, and I'd rather re-run a correct assessment than let one unverifiable quote into a signed packet.
  • Two retries is a guess tuned on our own failure data, not a law: too few and you escalate noise a reviewer could have avoided, too many and you burn latency and tokens converging on the same broken answer.
  • Making abstention cheap does raise the abstention rate, which is why the eval scores false abstentions as a real cost rather than treating every refusal as prudence.
  • Character offsets are brittle against re-published or re-paginated source documents, so we pin a content hash and treat a hash mismatch as a re-assessment trigger rather than pretending the old spans still hold.
